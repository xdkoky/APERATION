# APERATION

Forgatási napvezérlő 1st AD-knek. Telefonon fut, net nélkül is.

**App:** https://xdkoky.github.io/APERATION/base/ – telefonon a főképernyőre kell tenni (Megosztás → Főképernyőhöz adás).

## Mit tud

- **Most:** óra, visszaszámláló, várható wrap, Kész / Vissza / +5′, take-stopper, a következő beállítás és fényváltás.
- **Take-napló:** take-stopper, jó take csillag és jegyzet minden take-hez; az Időrendben shotonként visszanézhető, és a nyomtatott szkriptlapra is rákerül. Közös munkában a szkriptes vezérlési jog nélkül is vezetheti.
- **Szerepek kipróbálása:** Terv → Csapat: egyedül, egy eszközön átválthatsz bármelyik pozíció nézetére (mit lát, mit tehet); próba közben semmi nem mentődik.
- **Terv:** Excel betöltése (a `base/Forgatasi_sablon.xlsx` sablonnal a legbiztosabb) vagy beírás az appban, blokkok húzással átrendezve, mentés Excelbe, korábbi projektek.
- **Közös munka:** pozíciónkénti belépőkód, beállítható, ki mit lát, és ki vezérelheti a napot (Firebase).
- **Nyomtatás:** diszpó, forgatókönyv (a sztori), shotlist, szkript (a szkriptes lapja, sok jegyzethellyel) – A4, PDF-be is.
